# Note App 📝

A fast, modern, and responsive note-taking app built with **React 19**, **Vite**, and **pnpm**.

## ✨ Features

- 📱 **Fully Responsive** – Optimized for mobile, tablet, and desktop with a mobile slide-up drawer.
- 🌓 **Dark & Light Mode** – Instant toggle with system preference detection and saved settings.
- 🔍 **Instant Search & Sort** – Real-time search across notes with flexible sorting options.
- 🏷️ **Categories** – Color-coded organization (Work, Personal, Ideas, Study, General).
- ✏️ **Inline Editing** – Edit notes in place with `Ctrl/Cmd + Enter` keyboard shortcuts.
- 📊 **Progress Tracking** – Filter tabs, task completion progress bar, and bulk clear.
- 💾 **Offline First** – Automatic local storage persistence with zero server required.

## 🚀 Quick Start

```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev

# Build for production
pnpm build

# Run linter
pnpm lint
```

## 🛠️ Tech Stack

- **React 19** + **Vite 8**
- **pnpm**
- **@heroicons/react**
- **Modern CSS** (CSS Variables, Flexbox & Grid)
